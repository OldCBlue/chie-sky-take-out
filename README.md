# 🍱 苍穹外卖（Sky Takeout）- 智慧外卖訂食システム

> **フルスタック × AI統合** の飲食店向けWebプラットフォーム  
> SpringBoot + Vue3 + WeChat Mini Program + **Dify RAG AI客服**

---

## 📌 プロジェクト概要

「苍穹外卖」は、飲食店の**注文管理・後台運営・AI顧客対応**を一体化したフルスタックWebシステムです。  
本プロジェクトの最大の特徴は、**Dify（RAGフレームワーク）とDeepSeek-V3 LLMを統合したAIカスタマーサポート機能**の独自実装にあります。

---

## 🏗️ システム構成

```
chie-sky-take-out/
├── sky-take-out/               # バックエンド（Java / SpringBoot）
├── project-sky-admin-vue-ts/   # 管理後台（Vue3 + TypeScript）
└── mp-weixin/                  # ユーザー端末（WeChat ミニプログラム）
```

### アーキテクチャ図

```
[WeChat ミニプログラム]  ←→  [SpringBoot API]  ←→  [MySQL / Redis]
[管理後台 Vue3 + TS]    ←→        ↓
                             [Dify AI Engine]
                             ├── DeepSeek-V3 (LLM)
                             ├── ナレッジベース (RAG)
                             └── ハイブリッド検索 + Rerank
```

## 🤖 AI機能（最重要機能）

### AIカスタマーサポート（Dify × RAG）

本システムの中核となるAI機能です。単純なチャットボットではなく、**RAG（Retrieval-Augmented Generation）アーキテクチャ**を採用し、店舗固有のデータに基づいた高精度な回答を実現しています。

#### 技術スタック

| コンポーネント | 技術 | 役割 |
|---|---|---|
| **RAGフレームワーク** | Dify | LLM・ナレッジベース・APIの統合管理 |
| **LLM** | DeepSeek-V3 | 自然言語理解・回答生成 |
| **ベクトル検索** | Hybrid Search | 意味的類似度によるドキュメント検索 |
| **精度向上** | Rerank（リランキング） | 検索結果の関連度スコア再評価 |
| **ナレッジベース** | 構造化テキスト（5セグメント） | 菜品・価格・分類情報の管理 |

#### RAGシステムの設計思想

```
ユーザーの質問（例：「辛い料理はありますか？」）
        ↓
  ハイブリッド検索
  ├── キーワード検索（BM25）
  └── ベクトル検索（意味的類似度）
        ↓
  リランキング（Rerank）
  └── 関連度スコアで上位ドキュメントを選定
        ↓
  DeepSeek-V3 で自然言語回答生成
  └── 「蜀味烤鱼・蜀味牛蛙など辛味メニューがございます。
       おすすめは馋嘴牛蛙（¥88）です！」
```

#### Difyプロンプト設計

```
あなたは"苍穹外卖"の公式スマートアシスタントです。
核心タスク：【知識库】の内容に基づいて菜品・価格・分類の問い合わせに回答する。
ルール：知識库に情報がない場合は正直に告知し、でたらめを言わない（幻覚防止）。
形式：菜品を推薦する際は名称と価格を列挙し、簡単に口当たりを説明する。
管理者情報：ユーザーが人的サポートを必要とする場合、管理者 admin（電話: 13812312312）に連絡するよう知らせる。
```

#### 構造化ナレッジベース（5セグメント）

| セグメント | 内容 | 召回回数 |
|---|---|---|
| 分段-01 | 业务知识库（構造化整理） | 1回 |
| 分段-02 | 餐厅基本信息 | 11回 |
| 分段-03 | 菜品分類体系（10分類） | 12回 |
| 分段-04 | 詳細菜品リスト（価格・備注付き） | 12回 |
| 分段-05 | 営業情報・連絡先 | - |

> **検索品質：高品質・混合検索モード**で安定稼働

## 🚀 ローカル起動手順

### 前提条件

```bash
- JDK 17+
- Node.js 18+
- MySQL 8.0+
- Redis 7.0+
- Docker（推奨）
```

### 1. データベース初期化

```sql
CREATE DATABASE sky_take_out CHARACTER SET utf8mb4;
-- sql/sky.sql を実行
```

### 2. バックエンド起動

```bash
cd sky-take-out
# application.yml の DB接続情報を設定
mvn spring-boot:run
# → http://localhost:8080
```

### 3. 管理後台起動

```bash
cd project-sky-admin-vue-ts
npm install
npm run dev
# → http://localhost:5173
```

### 4. AI客服設定（Dify）

```
1. Dify にサインアップ（https://dify.ai）
2. 新規アプリ → 「聊天助手」を作成
3. ナレッジベースを作成し、店舗データ（菜品・価格・営業情報）をアップロード
4. 召回設定：「高品質」「混合検索」「Rerank有効」に設定
5. LLM選択：DeepSeek-V3
6. プロンプト設定（上記参照）
7. API Keyを取得 → application.yml に設定
```

## 🎯 技術的工夫・課題解決

### 課題：RAGの検索精度

単純なキーワード検索では「辛い」「おすすめ」などの意図的クエリに対応できない問題がありました。

**解決策**：ハイブリッド検索（BM25 + ベクトル類似度）+ Rerankの組み合わせにより、語義レベルでの検索精度を実現。

### 課題：LLMの幻覚（Hallucination）

LLMが知識库にない情報を生成するリスクを抑える必要がありました。

**解決策**：プロンプトに「知識库に情報がない場合は正直に告知し、でたらめを言わない」という明示的な制約を追加。

### 課題：セグメント構造の最適化

ナレッジベースをひとつの巨大なテキストとして登録すると検索精度が低下します。

**解決策**：5セグメントに分割し、各セグメントに意味的に独立したコンテキストを持たせることで、召回精度を向上。
